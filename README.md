# Sistema de Análise de Crédito em Python

Projeto desenvolvido em Python para simular um sistema bancário de análise de crédito, utilizando informações como salário e score do cliente para avaliar a aprovação de empréstimos.

## Funcionalidades

- Validação do salário informado.
- Validação do score de crédito (0 a 1000).
- Aprovação ou recusa de empréstimos com base no score.
- Definição de taxas de juros conforme a pontuação.
- Cálculo do valor do empréstimo e dos juros.
- Exibição dos resultados no terminal.

## Tecnologias Utilizadas

- Python 3
- Google Colab
- GitHub

## Conceitos Aplicados

- Variáveis e tipos de dados
- Entrada e saída com `input()` e `print()`
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`while`)
- Operadores lógicos e matemáticos
- Formatação de valores monetários

## Como Executar

1. Baixe o arquivo `analise_credito.py`.
2. Abra em um ambiente Python, como o Google Colab ou VS Code.
3. Execute o código.
4. Informe o salário e o score solicitados.
5. Confira o resultado da análise de crédito.

## Objetivo

Praticar os fundamentos da programação em Python por meio de uma aplicação que simula regras de concessão de crédito.

**Observação:** projeto acadêmico desenvolvido para fins de aprendizado. As regras de aprovação e taxas são fictícias.
